#### 第一天

::: tip 行程安排
当前位置 → 新余 → 仙女湖 → 仙女湖鱼宴 → 抱石公园（晚间）
:::

::: tip 路线
居住:convenience_store:：新余市区（建议住在城北广场/胜利北路附近，交通便利，周边商场、餐饮丰富）需提前3-7天预定。
1. <font color="#3eaf7c">仙女湖</font>（建议游玩时间：半天至一天）
   1. 仙女湖是国家重点风景名胜区、国家4A级旅游景区，因东晋文学家干宝所著《搜神记》中"毛衣女下凡"的传说而得名，是"中国七夕情人节"的发源地。
   2. 景区面积198平方公里，水域面积50平方公里，湖中岛屿星罗棋布，有"江西千岛湖"之称。
   3. 主要景点：<font color="#3eaf7c">龙王岛</font>（登岛可俯瞰仙女湖全景）、<font color="#3eaf7c">桃花岛</font>、<font color="#3eaf7c">蛇岛</font>、<font color="#3eaf7c">傣家度假村</font>、<font color="#3eaf7c">爱情岛</font>等。
   4. 开放时间：<font color="#3eaf7c">8:30 - 17:30</font>
   5. 门票: 约 160元/人（含船票），具体以景区公告为准。
   6. 交通：新余市区乘坐<font color="#3eaf7c">502路</font>公交车可直达仙女湖景区，车程约30分钟；或自驾导航"仙女湖风景名胜区"。
   7. 推荐游玩方式：乘船游览各岛屿，感受湖光山色，春夏季景色最佳。
2. 中午可在仙女湖景区附近品尝<font color="#3eaf7c">仙女湖全鱼宴</font>。
   1. 仙女湖有机雄鱼头
   2. 清蒸仙女湖桂鱼
   3. 红烧仙女湖鳊鱼
   4. 干煸仙女湖小白鱼
   5. 鱼丸汤
3. 傍晚返回市区，可前往<font color="#3eaf7c">抱石公园</font>散步，感受新余文化气息。
   1. 景点位置：新余市渝水区抱石大道与公园北路交汇处
   2. 抱石公园是为纪念新余籍国画大师<font color="#3eaf7c">傅抱石</font>而建，园内有傅抱石纪念馆可参观。
   3. 开放时间：全天（纪念馆需白天参观）
   4. 门票：免费
:::

#### 第二天

::: tip 行程安排
仰天岗国家森林公园 → 孔目江湿地公园 → 新余市博物馆 → 胜利北路美食街
:::

::: tip 路线
1. <font color="#3eaf7c">仰天岗国家森林公园</font>（建议游玩时间：上午半天）
   1. 仰天岗是新余的"城市绿肺"，森林覆盖率高，空气清新，是登山徒步的好去处。
   2. 主要景点：仰天岗主峰（海拔约360米，登顶可俯瞰新余全城）、<font color="#3eaf7c">仰天书院</font>、<font color="#3eaf7c">崇庆寺</font>（千年古刹）。
   3. 开放时间：全天
   4. 门票：免费
   5. 交通：市区乘坐公交或打车即可到达，距离市中心约5公里。
   6. 建议清晨出发，登山约1-2小时，下山后可前往孔目江湿地公园。
2. <font color="#3eaf7c">孔目江湿地公园</font>（建议游玩时间：1-2小时）
   1. 国家级湿地公园，是城市中的生态绿洲，适合散步、骑行、拍照。
   2. 沿江而建，水清岸绿，白鹭成群，风景优美。
   3. 开放时间：全天
   4. 门票：免费
   5. 景点位置：新余市渝水区孔目江沿岸
3. <font color="#3eaf7c">新余市博物馆</font>（建议游玩时间：1-2小时）
   1. 了解新余历史文化的最佳场所，馆藏有傅抱石作品及相关文物。
   2. 开放时间：<font color="#3eaf7c">9:00 - 17:00</font>（周一闭馆，法定节假日除外）
   3. 门票：免费，需携带<font color="#3eaf7c">身份证</font>
   4. 景点位置：新余市渝水区仙来中大道
4. 晚上前往<font color="#3eaf7c">胜利北路步行街</font>品尝新余本地美食：
   1. <font color="#3eaf7c">水北豆腐</font>——新余特色名吃，以水北镇产出最为正宗，嫩滑爽口，豆香浓郁
   2. <font color="#3eaf7c">新余米粉</font>——江西米粉的代表之一，可炒可拌，搭配各种浇头
   3. <font color="#3eaf7c">渝水烧烤</font>——本地人最爱的夜宵，烤鱼、烤串种类丰富
   4. <font color="#3eaf7c">马洪皮蛋</font>——新余特产，蛋白晶莹剔透，蛋黄油润
   5. <font color="#3eaf7c">水北挂面</font>——手工制作，筋道爽滑
   6. <font color="#3eaf7c">仙女湖醉鱼</font>——以仙女湖鲜鱼腌制风干而成，可做伴手礼
:::

#### 第三天

::: tip 行程安排
分宜电厂螺蛳（必吃）→ 分宜万年桥 → 中国洞都 / 蒙山风景区
:::

::: tip 路线
1. 上午从新余市区出发，自驾或乘坐公交前往<font color="#3eaf7c">分宜县</font>（约30分钟车程）。
2. <font color="#3eaf7c">分宜电厂螺蛳</font>（午餐必吃！）
   1. :warning: 此"电厂"并非真的发电厂，而是指分宜县老电厂附近兴起的螺蛳美食聚集地。
   2. 分宜电厂螺蛳是新余最具代表性的地方美食，以独特的配方炒制，鲜香麻辣，螺肉肥美，汤汁浓郁，越嗦越上瘾。
   3. 推荐店铺（集中在分宜电厂生活区附近）：
      1. <font color="#3eaf7c">老字号电厂螺蛳店</font>——最早的几家之一，味道最正宗
      2. <font color="#3eaf7c">电厂胖子螺蛳</font>——本地人常去
      3. <font color="#3eaf7c">分宜电厂小罗螺蛳</font>——口碑好，分量足
   4. 除了招牌螺蛳，还推荐搭配：
      1. 炒米粉（拌螺蛳汤汁绝了）
      2. 烤鱼
      3. 炒花甲
      4. 炒时蔬（解辣）
   5. 人均消费约 40-60 元，经济实惠。
3. 饭后前往<font color="#3eaf7c">分宜万年桥</font>（免费参观）
   1. 万年桥是一座始建于明代的古石拱桥，横跨袁河，为江西省文物保护单位。
   2. 桥身古朴沧桑，适合拍照打卡，感受历史韵味。
   3. 景点位置：分宜县城南郊袁河之上
   4. 游玩时间：约30分钟
4. 下午可选择（二选一）：
   - **方案A：<font color="#3eaf7c">中国洞都</font>**（分宜）
     1. 中国洞都是一个大型溶洞群景区，被誉为"华东第一溶洞"。
     2. 洞内钟乳石千姿百态，配合灯光效果奇幻绚丽。
     3. 门票：约 80元/人
     4. 开放时间：<font color="#3eaf7c">8:30 - 17:00</font>
     5. 游玩时间：约2小时
   - **方案B：<font color="#3eaf7c">蒙山风景区</font>**
     1. 蒙山是分宜与新余交界处的一座名山，山势雄伟，古迹众多。
     2. 山中有蒙山书院遗址、古银杏树（秋季金黄一片，非常壮观）。
     3. 免费登山，适合喜欢户外徒步的游客。
     4. 游玩时间：约3-4小时
5. 傍晚返回新余市区或直接从分宜返程。
:::

#### 特色美食汇总

::: tip 新余必吃美食清单
1. <font color="#3eaf7c">分宜电厂螺蛳</font>——来新余不吃电厂螺蛳等于白来，新余美食第一名片！
2. <font color="#3eaf7c">仙女湖鲜鱼</font>——仙女湖水质优良，产出的鱼类肉质鲜美，推荐鱼头豆腐汤、清蒸桂鱼。
3. <font color="#3eaf7c">水北豆腐</font>——以当地优质黄豆和山泉水制作，豆香浓郁、口感嫩滑，可煎可煮可凉拌。
4. <font color="#3eaf7c">新余米粉</font>——江西是米粉大省，新余米粉筋道爽滑，推荐牛肉炒粉、猪血粉。
5. <font color="#3eaf7c">马洪皮蛋</font>——新余渝水区马洪乡特产，蛋白晶莹如琥珀，蛋黄油润流沙。
6. <font color="#3eaf7c">分宜腊肉</font>——分宜山区传统工艺熏制的腊肉，肥而不腻，炒辣椒或蒸着吃都极佳。
7. <font color="#3eaf7c">水北挂面</font>——纯手工拉制的挂面，细如发丝，煮后不糊不烂。
8. <font color="#3eaf7c">渝水烧烤</font>——新余夜宵文化的代表，胜利北路和暨阳一带的烧烤摊最为集中。
9. <font color="#3eaf7c">仙女湖醉鱼</font>——以米酒腌制、风干而成的鱼干，咸香微甜，是很好的伴手礼。
10. <font color="#3eaf7c">新余鸭头</font>——卤制鸭头，香辣入味，配啤酒绝佳。
:::

#### 注意事项

::: tip 相关注意事项
1. 携带物品
   1. <font color="#3eaf7c">身份证</font>（博物馆、酒店入住等需要）
   2. <font color="#3eaf7c">衣服</font>（根据季节携带，新余属亚热带湿润气候，夏季炎热多雨、冬季湿冷）
   3. 舒适的运动鞋（仙女湖和仰天岗需要较多步行）
   4. 防晒用品（夏季仙女湖游船日晒较强）
   5. 雨伞/雨衣（江西雨季较长，特别是春夏之交的梅雨季节）
   6. 充电宝、现金（部分小店可能不支持移动支付）、相机/三脚架
2. 交通相关
   1. 高铁：<font color="#3eaf7c">新余北站</font>（高铁站），出站后可乘公交或打车到市区，约20分钟。
   2. 火车：<font color="#3eaf7c">新余站</font>（普速站），位于市区中心，交通便利。
   3. 市内公交：微信/支付宝可扫码乘车，票价1-2元。
   4. 出租车/网约车：起步价约7元，市区内出行方便。
   5. 前往仙女湖、分宜县可在市区乘公交或打车，也可自驾。
3. 住宿相关
   1. 推荐住在<font color="#3eaf7c">城北广场/胜利北路</font>附近，地处市中心，周边餐饮购物方便。
   2. 如主要游玩仙女湖，也可选择仙女湖周边的度假酒店或民宿。
   3. 节假日期间需提前1-2周预订酒店。
4. 饮食相关
   1. 新余菜属赣菜系，口味偏辣偏咸，不太能吃辣的朋友需要提前跟店家说明。
   2. 分宜电厂螺蛳偏辣，肠胃敏感者需适量。
   3. 仙女湖景区内餐饮价格较高，建议自备零食或出景区后用餐。
5. 最佳旅游时间
   1. <font color="#3eaf7c">春季（3-5月）</font>：气候宜人，仙女湖烟雨朦胧，最有意境。
   2. <font color="#3eaf7c">秋季（9-11月）</font>：秋高气爽，蒙山古银杏金黄，适合登山。
   3. 夏季较炎热，但仙女湖是避暑好去处；冬季湿冷，游客较少但别有风味。
:::

::: tip 其他景点，可供替换
1. <font color="#3eaf7c">昌坊度假村</font>
   1. 位于新余市渝水区良山镇，是一个集休闲、娱乐、餐饮于一体的乡村旅游度假区。
   2. 适合亲子游和周末休闲，有采摘园、垂钓区等。
   3. 门票：免费进入，内部项目另收费。
2. <font color="#3eaf7c">仙女湖国际赛车场</font>
   1. 位于仙女湖区，是江西省首个国际级赛车场。
   2. 喜欢赛车运动的朋友可以体验卡丁车等项目。
3. <font color="#3eaf7c">宽心小镇</font>
   1. 位于仙女湖大道旁，是一个新开发的文旅小镇。
   2. 古风建筑，适合拍照打卡，夜景灯光秀不错。
4. <font color="#3eaf7c">严嵩洞</font>（分宜县）
   1. 位于分宜县钤山镇，传说是明代权臣严嵩曾隐居的洞穴。
   2. 历史文化遗址，适合对历史感兴趣的游客。
5. <font color="#3eaf7c">钤阳湖</font>（分宜县）
   1. 分宜县的另一大湖泊，与仙女湖相连，游客较少，更加清静。
6. <font color="#3eaf7c">新余欢乐大世界</font>
   1. 位于仰天岗大道旁，游乐设施齐全，适合带小朋友游玩。
:::
